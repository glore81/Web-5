# JavaScript Laboratory Work — To-Do App & Tasks
## Temkeshev Aldiyar Se-2527
A set of practical tasks covering JavaScript basics and DOM manipulation, culminating in an interactive To-Do List mini-project.

## Project Structure
* **Task 0–1:** Basic syntax, variables, arithmetic operations, and console output.
* **Task 2–4:** DOM manipulation (changing text, styles, adding and removing list elements).
* **Task 5–6:** Mouse events (`mouseover`, `mouseout`) and keyboard events (`keyup`).
* **Task 7:** Simple interactive calculator.
* **Task 8 (Mini Project):** Interactive To-Do list supporting adding tasks, deleting, marking as completed (strike-through effect), and temporary array storage.

## Technologies Used
* HTML
* CSS
* JavaScript
* Bootstrap5

## How to Run
1. Download or clone the repository.
2. Open any `index.html` file in a modern web browser.
